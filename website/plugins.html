插件

更多的剧，来自插件。

片源插件由作者发布在 GitHub 上。点“安装”会打开一集；也可以在一集的“管理片源…”里从列表安装，或者填入插件的仓库 owner/repo。插件访问任何网站前都会先征得你的同意，不想用了可以随时停用或卸载。

    插件是第三方写的，一集不审核它的代码，只限制它能访问哪些网站；它看不到你的观看记录和电脑上的文件，但能把你搜的词和在看的剧发给这些网站。只装信得过的插件；发现恶意插件请告诉我们。

    发布你的插件

    照着插件开发指南写好插件，放进公开的 GitHub 仓库，加上 topic ichiwa-plugin，再加一个调用一集发布流程的 workflow，它会检查、打包并发布 plugin.zip。列表每天更新一次，通过检查的插件会出现在这里和一集的“管理片源…”里。

    jobs:
  release:
    uses: giuem/ichiwa/.github/workflows/plugin-release.yml@main
